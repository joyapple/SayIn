为什么做

一台没有麦克风的 Mac Mini

这不是一个商业项目，而是一个开发者为了解决自己的痛点，顺手做出来的小工具。

我有一台 Mac Mini，性能很强，但它没有麦克风，也没有摄像头。想用语音输入、想随手打几个字发给同事，只能抱个外接麦，或者对着手机敲完再复制粘贴——太麻烦了。

于是就有了 SayIt：手机当输入板，电脑当接收端。手机不用装任何 App，浏览器打开就能用。打字、语音都行，写完一点「发送」，文字就出现在电脑光标处。就这样，Mac Mini 终于有了「嘴」。

它能解决什么

那些让人抓狂的小麻烦

如果你也遇到过下面这些场景，SayIt 大概能帮上忙。

台式机没有麦克风

Mac Mini、组装机、没有内置麦的显示器，想语音输入只能外接设备。SayIt 直接用手机当麦克风和输入板。

手机打字再复制粘贴

在手机上写好长文，再手动复制、切到电脑、粘贴——步骤太多还容易丢。SayIt 一点「发送」直接到位。

跨设备传文字太繁琐

想把手机上的一段文字弄到电脑上，得绕一圈：发给「文件传输助手」、贴到云笔记、或邮件发自己。SayIt 只传文字，一条局域网 WebSocket 直连，实时又省事。

系统语音输入不好用

macOS 听写要联网、识别慢、还要按热键。SayIt 用你手机上熟悉的输入法，想怎么打就怎么打。

长文输入太累

在电脑键盘上敲几百字还行，上千字就累了。用手机熟悉的输入法，躺着走着都能写，写完一点「发送」就到电脑。

外接话筒又贵又不随身

一个像样的 USB 麦克风要花几百块，而且你不会时刻把它带在身边。手机却是你时时刻刻握在手里的，它本就是最现成的输入设备。

轻巧方便

小而美，不臃肿

没有账号、没有云端、没有订阅。一个 Node.js 文件跑起来，数据全在你自己电脑上。

  • 手机零安装

    不用下载 App，不用装插件。手机浏览器打开一个网址就能用，支持添加到主屏幕像 App 一样全屏。

  • 纯局域网，数据不出门

    手机和电脑在同一 WiFi 下直连，文字通过 WebSocket 实时传输，不经过任何第三方服务器。

  • 一条命令启动

    npm start 就能跑起来。依赖只有一个 WebSocket 库，体积小、启动快、不占资源。

  • 跨平台

    支持 macOS 和 Windows。macOS 还能自动粘贴到光标位置，Windows 可手动复制粘贴。

功能一览

该有的都有

围绕「输入 → 传输 → 落地」全链路打磨，细节足够日常使用。

手机输入 电脑接收

用手机输入法打字或语音识别，点发送实时传到电脑接收窗口。

应用切换

一键获取电脑运行中的应用，切换并自动粘贴到目标软件。

自动粘贴

发送后自动粘贴到电脑光标位置（macOS 需授权辅助功能权限）。

回车发送

粘贴后自动模拟回车，适配微信、QQ 等需要回车发送的场景。

追加模式

新内容追加到输入框末尾而非覆盖，适合分段撰写长文。

历史记录

发送记录持久化保存，支持一键重新发送，误删也不怕。

软件白名单

在设置页筛选常用软件，避免运行中列表太长干扰选择。

PWA 支持

添加到手机主屏幕，像原生 App 一样全屏使用，无地址栏。

开始使用

给 Mac Mini 一个「嘴」

克隆仓库，一条命令启动。手机打开网址，立刻就能用。

GitHub 仓库
$git clone <替换为你的仓库地址>.git
$cd phone-as-mic && npm install && npm start

需 Node.js 18+ · 手机与电脑在同一 WiFi · Apache-2.0 协议开源
