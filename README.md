# SayIt

> 把手机变成电脑的输入法。

Mac Mini 没有麦克风？打字不便？用手机自带的输入法（键盘 / 语音）写内容，点一下就传到电脑。手机零安装，浏览器打开即用。

**开源协议：Apache-2.0**

---

## 为什么做

这不是一个商业项目，而是一个开发者为了解决自己的痛点，顺手做出来的小工具。

> 我有一台 Mac Mini，性能很强，但它没有麦克风，也没有摄像头。想用语音输入、想随手打几个字发给同事，只能抱个外接麦，或者对着手机敲完再复制粘贴——太麻烦了。

于是就有了 SayIt：手机当输入板，电脑当接收端。手机不用装任何 App，浏览器打开就能用。打字、语音都行，写完一点「发送」，文字就出现在电脑光标处。就这样，Mac Mini 终于有了「嘴」。

| | |
|:---:|:---:|
| **0** | 手机端需安装的 App |
| **1** | 条 npm 命令即可启动 |
| **2** | 台设备（手机 + 电脑） |

## 它能解决什么

如果你也遇到过下面这些场景，SayIt 大概能帮上忙。

### 台式机没有麦克风

Mac Mini、组装机、没有内置麦的显示器，想语音输入只能外接设备。SayIt 直接用手机当麦克风和输入板。

### 手机打字再复制粘贴

在手机上写好长文，再手动复制、切到电脑、粘贴——步骤太多还容易丢。SayIt 一点「发送」直接到位。

### 跨设备传文字太繁琐

想把手机上的一段文字弄到电脑上，得绕一圈：发给「文件传输助手」、贴到云笔记、或邮件发自己。SayIt 只传文字，一条局域网 WebSocket 直连，实时又省事。

### 系统语音输入不好用

macOS 听写要联网、识别慢、还要按热键。SayIt 用你手机上熟悉的输入法，想怎么打就怎么打。

### 长文输入太累

在电脑键盘上敲几百字还行，上千字就累了。用手机熟悉的输入法，躺着走着都能写，写完一点「发送」就到电脑。

### 外接话筒又贵又不随身

一个像样的 USB 麦克风要花几百块，而且你不会时刻把它带在身边。手机却是你时时刻刻握在手里的，它本就是最现成的输入设备。

## 小而美，不臃肿

没有账号、没有云端、没有订阅。一个 Node.js 文件跑起来，数据全在你自己电脑上。

- **手机零安装** — 不用下载 App，不用装插件。手机浏览器打开一个网址就能用，支持添加到主屏幕像 App 一样全屏。
- **纯局域网，数据不出门** — 手机和电脑在同一 WiFi 下直连，文字通过 WebSocket 实时传输，不经过任何第三方服务器。
- **一条命令启动** — `npm start` 就能跑起来。依赖只有一个 WebSocket 库，体积小、启动快、不占资源。
- **跨平台** — 支持 macOS 和 Windows。macOS 还能自动粘贴到光标位置，Windows 可手动复制粘贴。

```
手机                          电脑
 │                            │
 │  WebSocket 局域网直连       │
 │  ──────────────────────────►│
 │  手机输入法打字/语音 → 发送   │  光标处出现文字
```

## 功能一览

围绕「输入 → 传输 → 落地」全链路打磨，细节足够日常使用。

| 功能 | 说明 |
|------|------|
| **手机输入 电脑接收** | 用手机输入法打字或语音识别，点发送实时传到电脑接收窗口 |
| **应用切换** | 一键获取电脑运行中的应用，切换并自动粘贴到目标软件 |
| **自动粘贴** | 发送后自动粘贴到电脑光标位置（macOS 需授权辅助功能权限） |
| **回车发送** | 粘贴后自动模拟回车，适配微信、QQ 等需要回车发送的场景 |
| **追加模式** | 新内容追加到输入框末尾而非覆盖，适合分段撰写长文 |
| **历史记录** | 发送记录持久化保存，支持一键重新发送，误删也不怕 |
| **软件白名单** | 在设置页筛选常用软件，避免运行中列表太长干扰选择 |
| **PWA 支持** | 添加到手机主屏幕，像原生 App 一样全屏使用，无地址栏 |
| **设置持久化** | 所有设置自动保存，重启服务不丢失 |

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) 18+
- 手机和电脑在同一局域网（同一 WiFi）

### 安装与运行

```bash
git clone <替换为你的仓库地址>.git
cd phone-as-mic
npm install
npm start
```

启动后会打印访问地址：

```
╔══════════════════════════════════════════════════════════════════╗
║                       ✦  SayIt  已启动  ✦                       ║
║                  手机写字板 → 电脑 · 优雅输入                    ║
╠══════════════════════════════════════════════════════════════════╣
║  💻 电脑接收窗口：http://localhost:8000/desk                     ║
║  ⚙️  设置页面：    http://localhost:8000/settings                ║
║  📱 手机入口：     http://192.168.x.x:8000                       ║
║  🔒 手机(HTTPS)：  https://192.168.x.x:8443                      ║
╚══════════════════════════════════════════════════════════════════╝
```

### 使用步骤

1. **电脑端**：浏览器打开 `http://localhost:8000/desk` 接收文字
2. **手机端**：用手机浏览器打开 `https://电脑IP:8443`（推荐 HTTPS）
3. **输入发送**：在手机上用输入法打字或语音输入，点「发送」即可
4. **切换软件**：点击顶部软件栏，选择电脑上的目标应用

## PWA 安装（推荐）

为了获得类似原生 App 的全屏体验（无地址栏），请通过 **HTTPS** 访问并添加到主屏幕。

### Android（Chrome / Edge）

1. 手机浏览器打开 `https://电脑IP:8443`
2. 首次访问时信任自签证书（点击「高级」→「继续前往」）
3. 页面顶部会弹出「安装 SayIt」提示，点击「安装」
4. 从主屏幕打开即可全屏使用，无地址栏

### iOS（Safari）

1. Safari 打开 `https://电脑IP:8443`
2. 首次访问时信任自签证书
3. 点击底部「分享」→「添加到主屏幕」
4. 从主屏幕打开即可全屏使用

> **注意**：通过 HTTP（端口 8000）添加到主屏幕会保留地址栏。必须使用 HTTPS（端口 8443）才能实现全屏 PWA 体验。

## 设置页面

打开 `http://localhost:8000/settings` 配置以下选项：

| 设置项 | 说明 |
|--------|------|
| 自动粘贴 | 发送后自动粘贴到电脑光标位置（需辅助功能权限） |
| 追加模式 | 新内容追加到输入框末尾，而非覆盖 |
| 粘贴后回车 | 自动粘贴后模拟回车，适配需要回车发送的软件 |
| 软件白名单 | 筛选可切换的软件，留空则显示全部运行中应用 |

所有设置自动持久化到 `data/settings.json`，重启不丢失。

## macOS 权限配置

### 辅助功能权限（自动粘贴需要）

如果开启了「自动粘贴」功能，需要授权辅助功能权限：

1. 打开 **系统设置 → 隐私与安全性 → 辅助功能**
2. 将运行 SayIt 的终端应用（如「终端」「iTerm」）添加并勾选

### 信任自签证书（HTTPS 访问）

首次通过 HTTPS 访问时，浏览器会提示证书不受信任：

- **Android Chrome**：点击「高级」→「继续前往」
- **iOS Safari**：点击「显示详细信息」→「访问此网站」
- **macOS**：可双击 `certs/cert.pem` 导入到钥匙串并设为始终信任

## 技术架构

```
手机浏览器                    电脑浏览器
   │                            │
   │  WebSocket (文字传输)       │  WebSocket (文字接收)
   │                            │
   └─────────► server.js ◄──────┘
                  │
                  ├── HTTP  (8000) — 手机入口 + 电脑端页面
                  ├── HTTPS (8443) — PWA 全屏模式
                  ├── 静态文件服务
                  ├── 应用列表获取 (lsappinfo + ps)
                  ├── 自动粘贴 (osascript keystroke)
                  └── 设置/历史持久化
```

- **通信**：WebSocket 实时双向传输，纯局域网，不经过第三方服务器
- **应用列表**：`lsappinfo`（获取显示名）+ `ps`（兜底补充），零权限
- **应用切换**：`open -a`（零权限）+ `osascript`（兜底）
- **自动粘贴**：`pbcopy` 写入剪贴板 + `osascript` 模拟 Cmd+V
- **PWA**：manifest.json + Service Worker 离线缓存

## 常见问题

### 手机打不开页面？

- 确认手机和电脑在同一 WiFi
- 确认电脑防火墙未阻止 8000/8443 端口
- 尝试用 HTTPS（8443 端口）访问

### 发送后电脑没有内容？

- 刷新电脑端 `http://localhost:8000/desk` 页面
- 确认页面显示「已连接」

### 自动粘贴失败？

- macOS 需要在「系统设置 → 隐私与安全性 → 辅助功能」中授权终端应用
- Windows 暂不支持自动粘贴，可手动复制粘贴

### PWA 打开后有地址栏？

- 必须通过 **HTTPS**（8443 端口）添加到主屏幕
- HTTP（8000 端口）添加到主屏幕会保留地址栏
- iOS 请使用 Safari 添加，Android 请使用 Chrome/Edge

### 识别不到运行中的软件？

- 点击设置页「加载运行中应用」刷新列表
- 系统自带应用（访达、控制中心等）会自动过滤
- 可手动添加白名单指定常用软件
